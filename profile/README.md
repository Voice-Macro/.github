# Voice Macro - Spoken Commands for Steps on Your Own PC

## Advanced Use Cases for Voice Macro

**Scenario 1: Repeated lab click** - Map one Voice Macro phrase to the action you already perform by hand.
Keep the phrase short so VoiceMacro does not fire on ordinary talk.
**Scenario 2: Two apps on one desk** - Point a command at the window you named, not at every window.
Test it once before you rely on it during a timed step.
**Scenario 3: Shared computer** - Keep your VoiceMacro list separate from someone else's profile.
Skip a machine you do not sign in to.
**Scenario 4: Next session** - Reopen the same command list and confirm the microphone still reaches Voice Macro.
Remove a command you no longer use.

## Understanding Voice Macro Core Components

- **Phrase** - the words that should fire Voice Macro.
- **Action** - the single step VoiceMacro performs.
- **Microphone** - the headset you own and already selected.
- **Window target** - the app the command is allowed to reach.
- **Profile** - the saved Voice Macro list for this desk.
- **Test pass** - one spoken try before the command stays.
- **Prune** - remove a VoiceMacro line you no longer want live.
